# Andreea Simon — Next.js Marketing Portfolio

Luxury/feminine editorial portfolio website built with Next.js.

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Deploy on Vercel
1. Create a GitHub repository and upload these files.
2. Go to Vercel.com and import the repository.
3. Framework preset: Next.js.
4. Click Deploy.

## Edit content
- Main page text: `app/page.tsx`
- Design styling: `app/globals.css`
- Images: `public/assets/`
